# 社群聯動試用 v1.2.0-preview.6

測試首頁：https://pocket-atlas-auth.huayang-hsu.workers.dev/account/community
個人頁編輯：https://pocket-atlas-auth.huayang-hsu.workers.dev/account/
清單與發布：https://pocket-atlas-auth.huayang-hsu.workers.dev/account/community#manage

此測試站與 GitHub Pages 正式首頁分開，使用同一個 Firebase 登入與 Worker Session。
既有正式站的 William 頁與清單不會自動轉成新帳號的所有物。

## 測試者流程
1. 管理者先把 Email 加入 creator_invitations；不會自動寄信。
2. 使用 Google 或已驗證的 Email/密碼登入。個人頁按「儲存並公開」後會直接更新公開頁。
3. 可預覽個人頁，再儲存公開；頭像與 Banner 一同公開，Email 不公開。
4. 新增封面、清單名稱、介紹、HTTPS 地圖連結、目的地、主題標籤。顯示狀態預設公開，按儲存即發布；可改為隱藏。首次公開清單會同時公開已儲存的個人頁。
5. 測試首頁按最近發布時間倒序（同秒以 ID 排序），12 筆一頁。點作者可看其個人頁。其他人發布後按重新整理可見，無背景輪詢。
6. 可取消清單發布，或隱藏整個個人頁。隱藏個人頁會連帶隱藏其清單；重新發布個人頁會恢復先前仍標為發布的清單。

## 資料與限制
- 私人資料與公開快照分開。儲存個人頁會公開；清單依選擇的公開／隱藏狀態更新。部分失敗會顯示錯誤，需重試。
- 公開測試內容可被任何取得網址者看到，不是邀請者限定閱讀；頁面有 noindex，但這不是存取控制。
- 沒有把圖片送到外部儲存供應商；發布圖片複製至既有 D1 公開快照表，私人原檔保留。
- 每帳號最多 20 份清單、每日 300 次發布/編輯操作；目前無刪除 UI，可取消發布。
- 只保存使用者貼入的連結，不抓取 Google 清單內容，不生成虛構人氣。
- 繁體中文和 English；原文內容不自動翻譯。主題/目的地暫為文字欄位，不與正式內容庫自動合併。
- 尚無審核管理 UI、開放註冊、正式首頁同步或搜尋；維持小規模受邀測試。
- 停權 creator_users.suspended=1 同時阻擋帳號和公開快照。限管理者操作。

## 驗證
63 項 Node API/單元測試通過；兩個独立 Chrome context 驗證各自發布、共同首頁、作者頁、隱藏、所有權隔離、內容逸出與手機寬度；原 Firebase 個人頁儲存/圖片重登入測試通過。測試帳號僅本機，未灌入線上資料。

封面會在瀏覽器轉成 WebP，最長邊 1000px、最多 128 KB，存於既有 D1 清單 JSON；公開 feed 僅傳圖片網址，隱藏內容的圖片端點回傳 404。未新增付費儲存服務。
