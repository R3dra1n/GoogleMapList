# 版本與備份

Git tag `v1.0.0` 指向 `586de71edaf9c53652d2cbd41c017bbc66036df9`。
本機完整備份：`.local-backups/2026-09-30-v1.0.0/`，包含 `workspace.tar.gz`、已驗證的 `history.bundle`、基準提交與 SHA256 校驗。

## v1.1.0-preview.1 — 本機預覽

分支 `codex/v1.1.0-preview`；package.json 是版本號唯一來源，建置後寫入 data.json、頁尾及預覽提示。

- 首頁加入「分享你的口袋世界，跟著喜歡的人出發。」與創作者頁入口。
- Fuse.js 本機模糊搜尋：名稱、別名、介紹、目的地、標籤、已确认景點。無付費搜尋 API。
- 來源創作者與整理者分開，不能把第三方頻道誤稱為已入駐帳號。
- YouTube 在詳情頁直向排列，點擊才載入，影片下方為遊記、景點與地圖。後台配置 videos 與 places 欄位；未替既有清單猜測影片或景點。
- 每個清單及創作者有可重新整理的獨立 HTML 路徑和靜態標題／OG；首頁分享封面仍沿用現有素材，專屬合成封面待後續設計。
- 新版預覽禁止 POST 等寫入、隱藏正式後台；人氣顯示 —，不影響正式統計。
- 保留既有目的地卡片及其直接開啟地圖入口。統一地圖入口資料轉接已預留，未遷移既有欄位。

### 尚未開放

創作者自行註冊、登入、所有權驗證、投稿審核、追蹤及排名；正式後台的新欄位與新版本都尚未發布。現有內容全部保留，管理員維護頁面不等於創作者已擁有可登入帳號。
搜尋只涵蓋本站已有資料，不會爬取 Google 清單全部景點，也不保證任意同義詞可命中。

### 驗證及預覽

`npm run build`、`npm test`；瀏覽器測試 `tests/catalog-browser.cjs` 需 Playwright 與本機 Chrome，使用 4174。
啟動 `PORT=4174 node scripts/serve.mjs`，開啟 http://127.0.0.1:4174/ 。
正式站目前保持不變。確認預覽後再安排正式版與發布驗證。

### 回復

在獨立資料夾還原備份或 checkout `v1.0.0`，不要在有新編輯的工作目錄直接 reset/覆蓋。先保存最新變更；雲端發布與資料庫回復另外處理。

## v1.1.0-preview.2 — 導航整理

全站共用文字導航：首頁／目的地／主題精選／創作者。移除探索清單的重複主導航入口，搜尋結果保留獨立路由。搜尋移至頁首，首頁不顯示搜尋篩選工具；創作者內搜尋收合。目的地只顯示大洲次導航，主題獨立顯示主題清單。目的地與主題卡片共用標籤呈現；空白標籤不自動捏造。版本 1.0.0 備份與 preview.1 提交皆保留，正式站未發布。

驗證：44 項單元測試；navigation-browser.cjs 檢查 1280/390 寬度、全站四個導航、主題與目的地區隔、標籤一致性及頁首搜尋；catalog-browser.cjs 回歸搜尋、詳情刷新和上下排列影片。

## v1.1.0-preview.3 — 統一卡片與搜尋

首頁、城市清單、主題與搜尋結果共用 catalogCard，顯示整理者、介紹、查看清單，再顯示目的地及主題標籤。各平台地圖入口保留於詳情頁。取消標籤顯示數量截斷，不自動增添不存在的標籤。搜尋結果僅使用頁首搜尋框，篩選保留收合；索引增加各語言遊記全文。
實際資料核對：「披薩」命中墾丁主題；「麵」沒有現存文字命中，目前收錄景點明細為 0。測試資料中的牛肉麵遊記可由「麵」命中，並验证三個標籤均出現在查看清單按鈕下方。

## v1.1.0-preview.4 — 卡片標題與頁尾

整理者緊接標題；國家英文名稱移近中文標題；標籤與人氣在同一列置中對齊，長標籤可換行。44 項測試及兩組瀏覽器回歸通過，另量測標籤與人氣中心點差小於 2px。
景點使用 places 結構化欄位（方案 A），正式 CMS 尚未發布新版。公開目錄未限制 owner=william，但自助投稿及審核尚未實作；未來應將公開目錄和編輯精選分開管理。

## v1.1.0-preview.5 — 創作者頁及卡片點擊

移除創作者頁內搜尋區；清單卡片使用原生連結延伸點擊區域，封面與留白可開啟詳情，作者及標籤保有各自連結。移除無區分用途的口袋清單角標。
首頁邏輯：featured 有有效內容時按指定順序；空白時顯示 catalogItems 前六筆（城市在前、主題在後），不是隨機、人氣排序或個人化推薦。
創作者自助裝飾尚未開放：預定可編輯姓名、簡介、頭像、Banner、社群連結，需伺服器登入／所有權驗證、圖片大小與格式限制、發布狀態。使用者不得設定首頁精選；策展權限保留管理員。不開放任意 HTML/CSS，維持一致排版。

## v1.1.0-preview.6 — 輪替、精選與作者歸屬

首頁改為台北日期每日輪替六份公開清單，主題精選由 curated 開關及 order 決定。七份既有主題保留精選，新建預設不精選。Google Maps 胡志明兩份改標原清單作者，William 為本站收錄者；保留來源網址。My Maps 大按鈕移除，嵌入區保留另開地圖文字備用連結。發布步驟和登入 MVP 計畫見 NEXT-RELEASE.md，等待 Preview 6 確認，尚未發布。
